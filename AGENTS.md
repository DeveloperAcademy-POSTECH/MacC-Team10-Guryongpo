## Mandatory Git Workflow

1. Update `main` and `develop` from the remote repository.
2. Create a GitHub issue for the implementation plan.
3. Create a small feature branch from the latest `develop`.
4. Implement only the approved scope.
5. Open a pull request targeting `develop`.
6. Close the related issue via `Closes #<issue-number>` in the pull request.
7. Never commit directly to `main` or `develop`.
