## 확정한 대응과 표시 정책

기존 축 이름과 시계 방향 순서를 유지한다.

| 인덱스 | 축 | 지표 | 0/40/70/85/100점 구간 |
|---|---|---|---|
|0|Agility|연속 유효 구간의 3초 평균 최고속도(km/h)|0 / 10 / 16 / 21 / 26|
|1|Activity|기록 시간당 이동량(m/min), 일시정지 제외|0 / 30 / 55 / 75 / 100|
|2|Potential|시간 가중 평균 심박 / 연령 추정 최대 심박|0 / 0.50 / 0.65 / 0.80 / 0.90|
|3|Mentality|14km/h 이상 시간 / 유효 속도 시간(%)|0 / 1 / 4 / 8 / 14|
|4|Endurance|마지막/첫 삼분의 일 구간의 분당 이동량 비율(%)|0 / 50 / 75 / 90 / 100|
|5|Explosivity|유효 측정 10분당 Sprint 횟수|0 / 0.5 / 1 / 2 / 3|

- 아마추어용 초기 제품 기준이며 검증된 축구 기술·정신력 평가가 아니다. 심박 부하는 운동 강도를 뜻한다.
- 점수는 구간 사이 선형 보간, 상한 100. 차트 값은 `1.5 + 3.5 × 점수/100`, 즉 반지름 30~100%.
- 누락 축은 실측 점수 평균으로 보완하되 최대 70점. 전부 없으면 50점 상당의 기본 표시(반지름 65%). 기본/보완은 평균에서 제외한다.
- Mentality·Explosivity·Potential의 시간 비율은 70% 이상 커버리지 필요. 속도 유효성은 기존 판정기를 재사용하고, Sprint 점수는 리포트와 동일한 저장 횟수를 사용한다. 기록 10분 이상 필요.
- Endurance는 15분 이상, 앞/뒤 각 70% 이상 측정 및 초반 20m/min 이상일 때 계산. pause를 제외한 활성 시간 구간을 비교한다.
- GPS 누락·무효·중복·점프를 정지로 채우거나 표시용 추정 경로를 측정 근거로 사용하지 않는다. 3초 연속 구간 없이 최고속도를 임의 추정하지 않는다.
- Potential은 당일 최고 심박을 분모로 사용하지 않는다. 생년 정보 읽기는 선택 사항이며 없으면 참고값 표시. 기존 심박 구간에서 쓰던 `220-age` 추정 기준을 메타데이터와 함께 보존한다.

## 구현

- DataConverter: 실제 시계열 집계, 6축 점수/표시 변환, 실측 기반 평균/최대 비교선.
- WorkoutData: 속도·정확도·시각, 운동 시간 경계/실제 기록 시간, 심박 기준 추가. 재조회 보존 로직 연결.
- iPhone: HKWorkoutRoute의 속도 시계열 연결, 저장된 심박 기준 또는 기록 당시 나이 추정 기준 사용.
- Watch: 버전 2와 선택적 개인 심박 기준 메타데이터 기록. 원본 운동/Power 필드 삭제 없음.
- HealthKit: 선택적 생년 정보 읽기 추가. 쓰기 권한/시작 필수 조건에는 포함하지 않음.
- 현재/전체 경기, 상세, 프로필의 비교선은 동일한 새 점수 기준 사용.
- 기존 축 이름 유지. ⓘ 설명 sheet와 측정 기반/참고값 구분을 KO/EN/ES/zh-Hans로 추가.
- UIKit 축 라벨은 번역된 문자열 기준으로 너비를 측정해 화면 밖 잘림을 줄임.
